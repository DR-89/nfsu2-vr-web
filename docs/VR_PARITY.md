## Software acceptance

The native feature inventory is implemented, with CopChase excluded. The
current build passes 830 fast checks, TypeScript and WASM/JS builds, hardware
GPU render tests, and actual PC game runs with simulated XR poses/controllers.
The latest full replay test passes physical shifts, six views, timeline, rewind
and normal return/exit with zero checksum or GPU errors. An earlier intermittent
streaming wait was not reproduced in the subsequent complete runs; no specific
fix for that original wait is claimed.

Three consecutive Online circuits reached results in a mixed VR/monitor
session, with over 2,100 mapped avatar samples per player and lobby return
between races. That probe reached its 900-second limit after the third result,
before the final statistics/quit steps. A separate full circuit/return run
passes those steps, both normal exits and zero GPU errors. World separation,
privacy, LAN, reconnect, co-op endpoint identities and model changes also have
separate integration coverage.

## Physical headset acceptance

Real headset optics, comfort, controller haptic support and seated reach remain
unverified. Simulated XR and GPU readback do not establish these hardware
properties. This is a hardware acceptance limit, separate from feature-port
completion; no successful physical headset run is claimed.

## Mirror edge regression (2026-11-10)

The shared native/Web mirror reprojection now validates each depth intersection in source texels. A foreground silhouette crossing cannot become a false reflected surface; sample density follows the projected ray length. The WebGPU regression compares both optical eyes against an analytic background with a nearby narrow occluder. It fails with the original shader and passes with the fix. The actual PC cockpit capture confirms removal of the speckled edge pattern, with zero GPU errors and normal exit. Hardware-headset optics remain a separate check.

## Mirror interior removal (2026-11-10)

At the user's request, mirrors show the retail road/traffic view with the local car excluded. The added cabin pass and reflected-head camera movement are removed in both native and Web builds. Adjusting the centre glass cannot move the source used by the side mirrors. The visible driving cockpit/body and remote avatars remain in their normal view passes. Stereo depth reprojection and retail mirror-mask filtering are retained.

## Movable screen depth (2026-11-10)

The translucent screen is composited after the cabin, wheel and hands against their finished depth. The native order is corrected; Web retains that order and uses a separate screen pipeline without depth writes. A WebGPU regression moves the real panel in front of and behind the authored wheel, comparing overlapping pixels at full/35% opacity for two eyes and 1x/4x samples. Native Vulkan readback checks 512 pixels at 0/35/100% opacity with the production screen shaders; the previous draw order fails the foreground case. Physical headset acceptance remains separate.
